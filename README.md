# Java Basics — DurgesgTutorials

A collection of beginner-friendly Java programs covering arrays, loops, conditionals, methods, simple games, and utility scripts. Great for practicing core Java syntax and concepts.

## Overview

- Focus: fundamentals — arrays, control flow, methods, string operations, math, and small console apps.
- Format: single-file programs you can compile and run individually.
- Audience: learners revising core Java topics with hands-on examples.

## Prerequisites

- Java JDK 8+ installed
- A terminal (PowerShell on Windows) or an IDE (VS Code/IntelliJ/Eclipse)

## Run Any Program (Windows)

1. Open a terminal in this folder.
2. Compile the file you want:
   ```powershell
   javac Array.java
   ```
3. Run the compiled class (omit `.java`):
   ```powershell
   java Array
   ```
   Replace `Array` with the program’s class name (usually matches the filename without `.java`). Repeat for any file you want to try.

## Topics Covered

- Arrays (1D and 2D), searching, and user input
- Control flow: `if/else`, `switch`, `for`, `while`, `do-while`, `break/continue`
- Methods, parameters, return values, and varargs
- Method overloading
- String utilities and substrings
- Math utilities, type casting, and simple calculations
- Mini-apps: games and small utilities (dice, RPS, guessing, converters)
